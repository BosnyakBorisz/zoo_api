--MONKEY--

GET/monkey            - összes majom lekérése
GET/monkey/:id        - egy majom lekérése
POST/monkey           - egy majom létrehozása
{
	name: név
	species: állatfaj
}
DELETE/monkey/:id     - egy majom törlése
PATCH/monkey/:id      - egy majom módosítása
{
	name: név
	species: állatfaj
}
POST/search           - majom kérése
{
	search: "bármi"
}
